# Nearkeep

让文件留在本地，让 Nicole 帮你找到它。

Nearkeep 是面向 macOS 的本地文件资料库。你可以将分散的文件复制或移动到自己选择的保存位置，按文件夹整理，在资料库中查找、预览，或定位到访达。Nicole 是陪伴这些操作的桌面角色。

## 主要功能

- 复制或移动文件、文件夹及混合批量，保留嵌套结构与空文件夹。
- 在选定的保存位置建立和管理真实文件夹；资料库和访达显示对应的文件层级。
- 收藏、常用文件夹、排序、预览、在访达中显示。
- 统一搜索：先返回普通检索结果，按需用本地 Qwen 语义检索补充；保留可删除的搜索历史。
- 自定义快捷键唤出快速搜索，以及中英文、浅深色主题和 Nicole 桌面设置。

## 安装

1. 在版本页下载 ZIP 和 `SHA256SUMS.txt`，放在同一目录。
2. 在该目录执行只读完整性检查：

   ```sh
   shasum -a 256 -c SHA256SUMS.txt
   ```

   应显示 `Nearkeep-1.0.0-macOS-arm64-unsigned.zip: OK`。
3. 解压得到 `Nearkeep.app`，放入“应用程序”。如已有旧版，先正常退出，再替换应用；不要删除保存文件的资料库目录。
4. 首次打开可能被 macOS 拦截。确认来源可信且校验一致后，按 [Apple 官方说明](https://support.apple.com/en-us/102445) 处理该应用的提示。不要关闭系统整体保护；若提示会损害电脑或文件已损坏，请停止并反馈。

## 开始使用

1. 打开资料库，在设置中选择一个专用保存文件夹。
2. 点击“上传”，或将文件、文件夹拖入资料库或桌面 Nicole。
3. 在确认页核对保存位置，选择操作：“复制”保留原位置文件；“移动”在安全保存成功后移出原位置。取消不会开始导入。
4. 完成后选择“查看”定位本批内容，或“完成”关闭提示。
5. 在搜索框输入文件名、关键词或描述；点击结果在资料库中定位，使用右侧操作在访达中显示或预览文件。
6. 在设置中录制快速搜索快捷键；Nearkeep 运行时可从其他应用唤出搜索。

## 本地模型与隐私边界

Qwen3-Embedding-0.6B 是语义检索模型，不是聊天或生成式摘要模型。模型随此安装包提供，当前检索链路使用本机文件、索引与模型，不把文件正文上传云端 AI。

核心文件管理和检索采用本地处理。macOS 自身的安全检查、默认邮件应用及用户主动打开的外部内容可能联网；尚未完成整个应用所有场景的断网与网络流量审计，因此不承诺“任何情况下完全离线”或“绝对安全”。

支持提取有文字层的 PDF，以及 TXT、Markdown、CSV、TSV、JSON、LOG 等文本。扫描 PDF 没有完整 OCR；Office 等其他格式不承诺正文检索。长文、大文件或处理时限可能导致仅索引部分内容，语义结果需结合原文核对。模型冷启动可能需要数十秒。

当前线上账号与云同步未开放。不要把本地资料库当作独立备份，请保留自己的备份方式。
